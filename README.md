# Spring Boot Assignment - TD2 to TD4

# spring-2-3
# STD24081

## Objective

This assignment aims to learn and implement fundamental Spring Boot concepts through three progressive exercises:

- **TD2**: Handling HTTP inputs (parameters, request body, headers)
- **TD3**: Managing response formats and errors
- **TD4**: Applying the Single Responsibility Principle (SRP)

---

## Technologies Used

- Java 17+
- Spring Boot 3.x
- Maven
- IntelliJ IDEA
